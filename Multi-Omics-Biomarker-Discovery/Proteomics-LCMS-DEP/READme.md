🧬 Proteomics – LC-MS Differential Expression Analysis (DEP)

Objective:

To analyze protein expression changes and identify differentially expressed proteins associated with disease.

🔬 Workflow

Processed LC-MS proteomics dataset
Performed normalization and preprocessing
Applied statistical analysis to identify differentially expressed proteins (DEP)
Evaluated significant protein-level changes between conditions

🛠 Tools Used

R (limma)
Data preprocessing and normalization techniques

📊 Outputs

Differential protein expression results (DEP)
(Visualization results will be updated)

💡 Key Insight

Observed limited but meaningful changes in protein expression
Highlighted the complexity of post-transcriptional regulation
Demonstrated that protein-level changes may not directly correlate with gene expression

🔗 Relevance to Multi-Omics

Proteomics provides functional insight at the protein level, complementing transcriptomics and epigenomics to enable a more comprehensive multi-omics understanding of disease mechanisms.
