🧬 Epigenomics – DNA Methylation Analysis (DMR)

Objective:

To identify differentially methylated regions (DMRs) and understand epigenetic regulation associated with disease.

🔬 Workflow

Loaded DNA methylation dataset
Performed normalization and preprocessing
Applied statistical analysis to identify DMRs
Evaluated significant methylation changes between conditions
Visualized results using volcano plot

📊 Outputs

Methylation volcano plot
DMR results (significant hyper/hypomethylated regions)
🛠 Tools Used
R (limma)
Data visualization (ggplot2)

💡 Key Insight

Identified regions with significant methylation changes
Highlighted potential epigenetic regulation mechanisms
Demonstrated how methylation may influence gene expression

🔗 Relevance to Multi-Omics

This analysis complements transcriptomics by providing insight into epigenetic control of gene expression, enabling a more comprehensive understanding of disease mechanisms.
