🧬 RNA-seq Differential Expression Analysis (RA)

Objective:
Identify differentially expressed genes in Rheumatoid Arthritis using transcriptomics data.

🔬 Workflow:
Data retrieval from GEO datasets
Normalization using limma
Differential gene expression analysis
Visualization using volcano plot and heatmap
📊 Outputs:
DEG results (CSV)
Volcano plot
Heatmap
🛠 Tools:
R (limma, GEOquery, pheatmap)
