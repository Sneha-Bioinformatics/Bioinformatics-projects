🧬 RNA-seq Differential Expression Analysis (RA)

Objective:
Identify differentially expressed genes in Rheumatoid Arthritis using GEO datasets.

Workflow:

Data retrieval using GEOquery
Normalization using limma
Differential expression analysis
Visualization (volcano plot, heatmap)

Tools Used:
R, limma, GEOquery, pheatmap
Key Results:

Identified significantly upregulated and downregulated genes
Visualized expression patterns using heatmaps
Generated volcano plot for significance analysis
