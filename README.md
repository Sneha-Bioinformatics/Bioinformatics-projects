# Bioinformatics Projects

## Differential Gene Expression (DEG) Analysis

This repository contains a basic implementation of a DEG analysis workflow using R.

### Overview
This project simulates gene expression data and calculates log fold change to identify differentially expressed genes.

### Steps Performed
- Generated synthetic gene expression dataset
- Calculated log fold change (logFC)
- Visualized results using basic plotting

### Tools & Technologies
- R Programming
- Data Analysis

### Purpose
This project demonstrates foundational concepts in transcriptomics data analysis and bioinformatics workflows.
